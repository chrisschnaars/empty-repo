---
title: Predictive Document Verification
excerpt: >-
  Predictive Document Verification (DocV) confirms the authenticity of a
  government-issued ID, matches the Personal Identifiable Information (PII)
  extracted from the ID against the input information, and matches the ID
  headshot to a consumer-submitted selfie using facial biometric analysis.

  The DocV APIs in this section allow you to integrate DocV services into your
  application.
